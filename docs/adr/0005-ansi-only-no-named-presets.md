# Tema fica 100% ANSI 16 (papel→índice), sem RGB arbitrário e sem presets nomeados

Cogitamos permitir RGB/true-color arbitrário no tema (o que daria fidelidade exata a presets populares como Catppuccin/Gruvbox, independente do terminal do usuário), mas isso quebraria justamente a vantagem que motivou o ANSI 16 desde o início: o taskthing herdar automaticamente a paleta que o usuário já tem configurado no seu emulador de terminal, sem esforço nenhum e sem risco de destoar visualmente do resto do shell. Decidimos manter o tema estritamente como um remapeamento de papel semântico → índice ANSI (0-15) — o taskthing nunca emite RGB, só o índice; quem resolve a cor real é sempre o emulador de terminal.

Consequência: como os índices ANSI já seguem uma convenção semântica comum entre a maioria dos esquemas de terminal populares (índice 1≈vermelho/erro, 2≈verde/sucesso, 3≈amarelo/aviso, 4≈azul/destaque), um único mapeamento padrão de papel→índice já deve funcionar bem visualmente em praticamente qualquer terminal, sem o usuário precisar configurar nada. Por isso cortamos os "temas pré-definidos" nomeados (catppuccin, gruvbox etc.) do escopo — eles adicionariam pouco valor sobre um bom padrão único. Sobra apenas: **padrão** (role→índice fixo, cobre a maioria dos casos) e **customizado** (textarea com JSON papel→índice, pra quem quiser um tweak específico). O destaque do board virtual inbox segue a mesma regra — é o papel `inbox-accent`, com índice padrão hardcoded no código, não uma exceção com cor RGB própria. A cor por board (`taskthing set --board color <id> <ansi-color-name>`) também segue a mesma regra: escolhida entre os 16 índices ANSI, nunca hex/RGB — dá ao usuário liberdade de escolha sem reabrir a exceção.
